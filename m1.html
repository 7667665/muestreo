¿Por qué comprimimos señales?

Un archivo de audio sin comprimir de solo 3 minutos ocupa ~30 MB (CD-quality). Una imagen de 12 MP sin comprimir pesa ~35 MB. La compresión elimina redundancia e información imperceptible para reducir dramáticamente ese peso sin pérdida de calidad apreciable.

Parte 1 · Teoría

Compresión de Audio — Downsampling

¿Qué es el downsampling? Es la técnica de reducir la frecuencia de muestreo de una señal tomando solo cada N-ésima muestra. Si tomamos 1 de cada 2 muestras, la nueva tasa es la mitad. Esto reduce directamente el tamaño del archivo.

Simulación interactiva — Efecto del Downsampling

Factor N (tomar 1 de N) 1×
Frecuencia señal (Hz) 5 Hz
■ Señal original ■ Muestras elegidas (1/N) ■ Señal reconstruida
⚠️ ¡ALIASING DETECTADO! El factor de downsampling es demasiado alto para esta frecuencia. La señal reconstruida es distorsionada (regla de Nyquist: fs/N ≥ 2·f_señal).

Antes del downsampling

  • fs
    Frecuencia de muestreo original: típicamente 44,100 Hz (calidad CD)
  • N
    Número de muestras totales: grande, archivos pesados
  • B
    Bits por muestra: 16 bits (rango -32768 a +32767)

Después del downsampling (N=4)

  • fs
    Nueva frecuencia: 44,100 / 4 ≈ 11,025 Hz
  • N
    Número de muestras: reducido 4×
  • B
    Bits por muestra: 8 bits → otra reducción adicional
Relación de Compresión = (fs_original × bits_original) / (fs_nueva × bits_nuevos)
RC = (44100 × 16) / (11025 × 8) = 705,600 / 88,200 = 8:1
Condición de Nyquist: Para que el downsampling sea válido sin aliasing, la nueva frecuencia de muestreo debe ser ≥ 2 veces la frecuencia máxima del audio. Si el audio tiene componentes hasta 5,000 Hz, fs_nueva ≥ 10,000 Hz.

audioread(filename)

Lee un archivo de audio (WAV, MP3, FLAC, OGG). Retorna la matriz de muestras y (columnas = canales) y la frecuencia de muestreo fs en Hz.

MATLAB % Leer archivo completo
[y, fs] = audioread('bearsound.wav');

% Leer solo un rango de muestras
[y, fs] = audioread('bearsound.wav', [1, 200]);

% y: matriz [N_muestras x N_canales], valores en [-1, 1]
% fs: frecuencia de muestreo en Hz (ej: 44100)
Los valores de audio están normalizados entre -1 y +1, no en voltios reales.

audioinfo(filename)

Retorna una estructura con metadatos del archivo sin leer las muestras. Útil para verificar antes de cargar archivos grandes.

MATLAB info = audioinfo('bearsound.wav');

disp(info.SampleRate) % → 44100 Hz
disp(info.NumChannels) % → 1 (mono) o 2 (stereo)
disp(info.TotalSamples) % → número total de muestras
disp(info.Duration) % → duración en segundos
disp(info.BitsPerSample) % → 16 (típico)

downsample(x, N)

Retiene solo 1 de cada N muestras. No aplica filtro anti-aliasing por defecto — si hay frecuencias altas, se produce aliasing. Para señales de audio reales, es común aplicar un filtro pasa-bajas antes.

MATLAB % Factor de downsampling
N = floor(44100 / 11025); % = 4

% Submuestrear el vector de audio
y_down = downsample(y, N);

% Nueva tasa de muestreo
fs_new = fs / N; % = 11025 Hz

% Verificar tamaños
fprintf('Original: %d muestras → Nuevo: %d muestras\n', length(y), length(y_down));

audiowrite(filename, y, fs)

Escribe un archivo de audio. Se puede especificar BitsPerSample para reducir aún más el tamaño.

MATLAB % Guardar en 16 bits (default)
audiowrite('audio_comprimido.wav', y_down, fs_new);

% Guardar en 8 bits (mayor compresión)
audiowrite('audio_8bit.wav', y_down, fs_new, ...
    'BitsPerSample', 8);

% y debe estar en rango [-1, 1]

floor(x)

Redondea hacia el entero inferior. En esta práctica se usa para calcular el factor de downsampling de forma exacta.

MATLAB floor(3.9) % → 3
floor(44100/11025) % → 4 (factor N)
floor(-1.2) % → -2 (hacia abajo)

fft() y fftshift() — Espectro de audio

clc; clear; close all;

%% 5.1 Importar archivo de audio
filename = 'bearsound.wav';

%% 5.2 Leer vector de audio y frecuencia de muestreo
[y, fs] = audioread(filename);

%% 5.3 Información del archivo de audio
info = audioinfo(filename);
disp(info);

%% 5.4 Figura 1: 200 primeras muestras + primeros 2 segundos
muestras_2s = 2 * fs; % nº de muestras en 2 segundos
t = (0:muestras_2s-1) / fs; % vector de tiempo en segundos

figure(1);
subplot(2, 1, 1);
plot(y(1:200), 'Color', [0 0.9 0.6]);
title('200 primeras muestras');
xlabel('Muestra'); ylabel('Amplitud');

subplot(2, 1, 2);
plot(t, y(1:muestras_2s), 'Color', [0 0.9 0.6]);
title('Primeros 2 segundos de audio');
xlabel('Tiempo (s)'); ylabel('Amplitud');

%% 5.5 Figura 2: Espectro de frecuencias (señal original)
N_total = length(y);
Y_fft = abs(fftshift(fft(y)));
f_eje = linspace(-fs/2, fs/2, N_total);

figure(2);
plot(f_eje, Y_fft);
title('Espectro - Señal Original');
xlabel('Frecuencia (Hz)'); ylabel('Magnitud');

%% 5.6 Submuestreo (Downsampling)
fs_objetivo = 11025; % nueva fs objetivo
N = floor(fs / fs_objetivo); % factor = 4
y_down = downsample(y, N); % submuestrear
fs_new = fs / N; % nueva tasa de muestreo

%% 5.7 Figura 3: 2s + espectro de señal submuestreada
muestras_2s_new = 2 * fs_new;
t_new = (0:muestras_2s_new-1) / fs_new;

figure(3);
subplot(2, 1, 1);
plot(t_new, y_down(1:muestras_2s_new));
title('Señal Submuestreada - Primeros 2s');

subplot(2, 1, 2);
N_d = length(y_down);
Y_down = abs(fftshift(fft(y_down)));
f_d = linspace(-fs_new/2, fs_new/2, N_d);
plot(f_d, Y_down);
title('Espectro - Señal Submuestreada');

%% 5.8 Crear archivo de audio comprimido (8 bits)
audiowrite('bearsound_comprimido.wav', y_down, fs_new, ...
    'BitsPerSample', 8);

%% 5.9 Calcular relación de compresión
bits_orig = info.BitsPerSample;
RC = (fs * bits_orig) / (fs_new * 8);
fprintf('Relación de compresión: %.2f : 1\n', RC);

Compresión de Imágenes — DCT y JPEG

¿Qué es la DCT (Transformada de Coseno Discreta)?
Convierte un bloque de pixeles del dominio espacial (intensidades) al dominio frecuencial (coeficientes de cosenos). La mayor parte de la energía visual se concentra en muy pocos coeficientes — los de baja frecuencia.
DCT-2D: F(u,v) = C(u)·C(v) · Σ Σ f(x,y)·
cos[(2x+1)·u·π/16] · cos[(2y+1)·v·π/16]

C(0)=1/√2, C(n≠0)=1

Componente DC vs AC

DC (F[0,0]): El coeficiente en la esquina superior izquierda del bloque DCT. Representa el promedio de todos los pixeles del bloque — el valor de "brillo general". Es el más importante.

AC (resto): Los demás coeficientes representan variaciones — texturas, bordes, detalles finos. Los de alta frecuencia (esquina inferior derecha) son los menos perceptibles y los primeros en eliminarse.

Proceso JPEG — Paso a Paso

  • 1
    Convertir imagen a escala de grises (im2gray). Rango 0–255.
  • 2
    Restar 128 para centrar los valores en torno a 0 (–128 a +127).
  • 3
    Dividir en bloques de 8×8 pixeles.
  • 4
    Aplicar DCT 2D a cada bloque → 64 coeficientes por bloque.
  • 5
    Cuantizar dividiendo cada coeficiente por la tabla Q y redondeando. Los valores pequeños se vuelven cero.
  • 6
    Guardar (muchos ceros → alta compresión por codificación RLE/Huffman).
  • 7
    Reconstrucción: Multiplicar por Q, aplicar IDCT, sumar 128.

Tabla de Cuantización JPEG para Luminancia

Los coeficientes DCT se dividen por estos valores y se redondean. Valores altos = más pérdida. Valores altos están en las frecuencias altas (esquina inf-der) porque el ojo humano es poco sensible a ellos.

■ Baja cuantización (más detalle) ■ Media cuantización ■ Alta cuantización (más pérdida)

MATLAB · practica6_imagen.m %% ── PRÁCTICA 6: COMPRESIÓN DE IMAGEN ─────────────────────────────
clc; clear; close all;

%% 5.1 Leer imagen
img = imread('imagen.png'); % reemplaza con tu imagen

%% 5.2 Convertir a escala de grises
img_gray = im2gray(img);
img_d = double(img_gray); % para operaciones matemáticas

%% 5.3 DCT global de la imagen
img_dct_global = dct2(img_d);

%% 5.3 Mostrar dominio DCT (escala log para visualizar)
figure(1); imshow(log(1 + abs(img_dct_global)), []);
title('Imagen en dominio DCT'); colormap(jet);

%% 5.4 Tabla de cuantización JPEG (luminancia)
Q = [16 11 10 16 24 40 51 61; ...
     12 12 14 19 26 58 60 55; ...
     14 13 16 24 40 57 69 56; ...
     14 17 22 29 51 87 80 62; ...
     18 22 37 56 68 109 103 77; ...
     24 35 55 64 81 104 113 92; ...
     49 64 78 87 103 121 120 101; ...
     72 92 95 98 112 100 103 99];

%% 5.5 Cuantización por bloques 8×8
[rows, cols] = size(img_d);
img_quant = zeros(rows, cols);
img_recon = zeros(rows, cols);

for r = 1:8:rows
  for c = 1:8:cols
    bloque = img_d(r:r+7, c:c+7) - 128;
    D = dct2(bloque);
    D_q = round(D ./ Q); % cuantizar
    img_quant(r:r+7, c:c+7) = D_q;
    D_rec = D_q .* Q; % descuantizar
    img_recon(r:r+7, c:c+7) = idct2(D_rec) + 128;
  end
end

img_recon = uint8(max(0, min(255, img_recon)));

%% 5.5 Mostrar imagen DCT cuantizada
figure(2); subplot(1,2,1);
imshow(log(1+abs(img_dct_global)),[]); title('DCT original');
subplot(1,2,2);
imshow(log(1+abs(img_quant)),[]); title('DCT cuantizada');

%% 5.7 Montage: original vs reconstruida
figure(3);
montage({img_gray, img_recon}, 'Size', [1 2]);
title('Original (izq) vs Reconstruida JPEG (der)');

%% 5.8 Variar factor de cuantización
for factor = [0.6, 1, 2]
  Q_var = round(Q * factor);
  % ... (repetir el proceso con Q_var)
end

%% 5.10 Tasa de compresión
zeros_totales = sum(sum(img_quant == 0));
total_coefs = rows * cols;
tasa = zeros_totales / total_coefs * 100;
fprintf('Coeficientes en cero: %.1f%%\n', tasa);

Interpretación de Resultados

Q × 0.6 (mejor calidad): Tabla más pequeña → divisores menores → más coeficientes sobreviven → más detalle preservado → menos compresión.

Q × 1.0 (estándar JPEG-75%): Balance entre calidad y tamaño. Típicamente 60–75% de coeficientes en cero.

Q × 2.0 (más compresión): Tabla mayor → divisores más grandes → más coeficientes se redondean a cero → artefactos de bloque visibles en bordes.

PSNR > 40 dB: Calidad excelente. 30–40 dB: Buena. <30 dB: Degradación visible.
